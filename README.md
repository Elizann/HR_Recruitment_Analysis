# 📊 Recruitment Analysis Dashboard | Power BI

## 📌 Project Overview
Developed an interactive Recruitment Analysis Dashboard in Power BI to monitor and analyze the end-to-end hiring process. The dashboard provides detailed insights into recruitment funnel performance, candidate progression, stage-wise conversion rates, hiring efficiency, and recruitment bottlenecks.

The report helps HR teams and stakeholders track applicant movement across hiring stages, identify high drop-off points, improve recruitment efficiency, and support data-driven hiring decisions.

---

# 🎯 Project Objective
To build a comprehensive recruitment analytics dashboard that enables stakeholders to:

- Monitor candidate progression across recruitment stages
- Analyze recruitment funnel performance
- Track hiring conversion rates
- Identify recruitment bottlenecks and drop-off stages
- Measure hiring efficiency and process effectiveness
- Improve decision-making in talent acquisition

# 📌 Key Insights

## 📈 Recruitment Funnel Performance
- The dashboard provides a complete view of candidate movement from application to hiring.
- Funnel analysis highlights recruitment efficiency at each hiring stage.

## 🚨 Bottleneck Identification
- Stage-wise drop-off analysis helps identify the highest candidate loss points during recruitment.
- Bottleneck detection supports optimization of screening and interview processes.

## 📊 Conversion Tracking
- Recruitment conversion metrics help HR teams evaluate the effectiveness of hiring strategies.
- Stage conversion analysis enables better pipeline management.

## ⏱ Hiring Efficiency
- Average days per stage analysis helps monitor recruitment turnaround time.
- Supports improving hiring speed and operational efficiency.
